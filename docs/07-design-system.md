# نظام التصميم v4 «دافئ تحريري» — إضاءات

> v4 (2026-09-28) يستبدل v3 «واقعي» بطلب العميل، مطابقاً للمراجع:
> `desktop_reference.html` (لوحة التحكم — سطح المكتب) و`mobile_reference.html` (الجوال: الرئيسية، الحصص، المالية) في جذر المستودع.
> التغيير **واجهة فقط**: لم تتغير المسارات ولا قاعدة البيانات ولا الصلاحيات ولا أسماء حقول النماذج ولا حماية CSRF.

## المبادئ
- **أسطح مسطحة بلا تدرجات ولا توهج**: التمييز بتباين الأسطح فقط — بيج (`--bg`) ⇐ كريمي (`--surface`) ⇐ داكن (`--panel`). يتحقق من ذلك `tests/design.test.ts`.
- **البرتقالي `--brand` هو اللون المميز الوحيد**: التقدّم، نقطة نهاية الرسم، التنبيهات، أرقام المتأخرات (`--brand-ink`).
- **تحريري**: الترحيب بـ Alexandria 300 بحجم 44px (30px جوال) والاسم وحده 600؛ الأرقام الكبيرة Alexandria 500 بحجم 34px (26px جوال) و`letter-spacing:-.8px`، والوحدة «ر.س» 13px باهتة.
- **أزرار كبسولية** (`999px`): الأساسي حبر داكن `--ink` بنص `--bg` وارتفاع 44–46px؛ الثانوي شفاف بحد `--border-btn`؛ الأيقوني دائرة 38–40px على `--surface`.
- **حركة هادئة**: 220ms `cubic-bezier(.2,.8,.2,1)`، ظهور خفيف `rise` + View Transitions، واحترام `prefers-reduced-motion`. لا مؤثرات مؤشر/إمالة/مغناطيس في اللوحات (تبقى في الموقع التعريفي فقط).

## الهيكل (App Shell) — `src/views/layout.tsx`
| العرض | التنقل |
|---|---|
| ≥ 1024px | **شريط علوي 68px بلا خلفية** وحشوة أفقية 40px: الشعار (دائرة 32px) + «إضاءات»، ثم **تبويبات كبسولية** للأقسام داخل حاوية `--bg-2`، وعلى اليسار: البحث (Ctrl+K)، الوضع الليلي، الإشعارات (نقطة برتقالية للجديد)، وكبسولة المستخدم. صفحات القسم كبسولات صغيرة تحت الشريط (`.subnav`). |
| 700–1023px | نفس الشريط بتبويبات أضيق، واسم المستخدم مخفي. |
| < 700px | رأس بسيط: الشعار في الرئيسية، أو **زر رجوع + عنوان القسم** في الصفحات الفرعية، مع أزرار الصفحة (مثل «+» الداكن وتصدير). **شريط تنقل سفلي ثابت 84px** (+ safe-area) بخلفية شفافة وضبابية `blur(12px)`، 5 عناصر بأيقونة 22px ونص 10.5px، والنشط `--ink` 600. قائمة الحساب ورقة سفلية تضم الأقسام غير الموجودة في الشريط (مثل «الأشخاص»). |

- لا قائمة جانبية. الأقسام تأتي من `sectionsFor(role)` في `src/views/nav.ts` (≤ 6 أقسام، ≤ 5 في الشريط السفلي — `tests/nav.test.ts`).
- أزرار رأس الجوال تُمرَّر من الصفحة: `page(c, title, body, { actions: <…/> })`.
- البحث والانتقال السريع: `<dialog id="searchDlg">` بالصفحات والإجراءات السريعة لكل دور، يُفتح بزر البحث أو Ctrl/⌘+K، مع أسهم ↑↓ وEnter.

## المكونات
| المكون | الوصف |
|---|---|
| `.hello` | الترحيب التحريري + وصف 14px + أزرار (على الجوال زران متساويان `flex:1`). |
| `.card` / `.stat` | كريمي، نصف قطر 24px، حشوة 22px (16px جوال)، بلا حد ولا ظل. `Stat` = تسمية 12.5px + رقم كبير + سطر فرعي؛ `tone="bad"` يلوّن الرقم `--brand-ink`. |
| `.panel` | اللوحة الداكنة «على الهواء الآن»: نقطة بث نابضة (`.live-dot`)، صفوف `.ls` (وقت ذهبي 15px، عنوان، «المعلمة · القاعة · الطلاب»، شريط تقدّم 3px)، «لاحقًا اليوم»، وبلاطات القاعات. |
| `AreaChart` | رسم مساحة SVG: خط `--brand` 2.2px، تعبئة `--brand-soft`، نقطة نهاية بحد بلون السطح، بلا شبكة. |
| `.seg` | مقسّم: حاوية `--bg-2` كبسولية بحشوة 4px، والنشط `--surface` + `--shadow-xs`. مبدّل الإيرادات أسبوعي/شهري يعمل بلا JS (راديو + `:has`). |
| `.dr` | صف قسط متأخر: صورة رمزية + اسم + دورة + مبلغ 600 + كبسولة «تذكير» أو «متأخر N أيام». |
| `.rate-box` | «نسبة التحصيل»: صندوق `--bg` برقم وشريط حبر. |
| `.days` / `LessonCard` | شريط 5 أيام (النشط حبر داكن) وبطاقات الحصص: الوقت + «مباشر» + القاعة، العنوان، «المعلمة · الدورة»، التقدّم، زر «انضمام» 32px. |
| `.badge` / `.pill` | كبسولات الحالة: مدفوع `--ok-50/--ok`، متأخر `--brand-50/--brand-ink`، مستحق `--bg-2/--ink-2`. |
| الجداول | داخل سطح كريمي، رؤوس 12px باهتة بلا خلفية، صفوف مفصولة بـ `--line`. على الجوال تتحول كل صف إلى **بطاقة** (آلية `data-label` في `app.js`)، والإجمالي بطاقة داكنة. |
| الحقول | ارتفاع 46px، نصف قطر 14px، حد `--line-2`، والتركيز حد `--ink`. |
| غرفة الحصة والمشغل | إطار `--panel` داكن، وشريط التسجيل داكن بأزرار كبسولية؛ العلامة المائية ومنع التحميل كما هي. |

## الفحص
- `npm test` — يشمل `tests/design.test.ts` (لا تدرجات، التوكنز، تقليل الحركة) و`tests/shell.test.tsx` (لا قائمة جانبية، ≤ 5 في الشريط السفلي، زر الرجوع).
- `bash tests/e2e.sh` — 120 فحصاً وظيفياً.
- `python3 tests/visual/shoot.py [out] [--dark] [--only=…]` — لقطات 1440 و390.
- `python3 tests/visual/crawl.py` — يزور كل الصفحات لكل دور: أخطاء JS، روابط 4xx، تجاوز أفقي، إتاحة.
- `python3 tests/visual/contrast.py` — تباين النص الفعلي WCAG AA في الوضعين والمقاسين.
